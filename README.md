## 4주차 반응형 수정

### 확인할 문제

작은 화면에서 메뉴, 기능 카드, 이메일 폼이 좁여 보였다.

### 수정한 내용

-viewport 메타 태그를 추가했다.
-콘텐츠에서 width와 max-width를 함께 사용했다.
-기능 카드 목록을 반응형 grid로 변경했다.
-768px 이하에섯 메뉴, 카드 폼을 한 열로 구성했다.

### 확인할 화면 너비

1100px / 769px / 768px / 390px

## 5주차 구독하기 버튼에 반응하기

### 사용자가 하는 행동
구독하기 창에서 이메일을 입력하고 버튼을 누른다

### 화면에서 바뀌는 내용
이메일을 입력하면 구독 완료 안내문구와 함께 버튼이 비활성화 됨.
이메일을 입력하지 않으면 버튼은 그대로 유지됨.

### 연결 코드
addEventListener("submit", handleSubscribe)로 구독 폼과 handleSubscribe() 함수를 연결
event.preventDefault()로 구독 시 페이지가 새로고침되는 것을 막았다.
textContent로 안내 문구와 버튼의 글자를 변경
classList.add("is-success")로 구독 완료 메시지의 CSS 스타일을 적용
disabled = true로 구독 완료 후 버튼을 비활성화
이메일이 비어 있는 경우, 함수를 완료하지 않고 멈춘다.

### 테스트 결과 확인

769px에서는 데스크톱 레이아웃이 유지되는지 확인
768px에서는 화면 너비에 따른 탭과 콘텐츠의 배치 변화를 확인
390px에서는 좁은 모바일 화면에서도 탭 버튼과 콘텐츠가 잘리거나 겹치지 않고 정상적으로 표시되는지 확인

## sarajeong interior decor -상담 신청 설정
-사용자: 인테리어에 고민이 있는 사람
-목표: 간단하게 개인 맞춤 상담을 신청할 수 있다.

### 사용자의 흐름
1. 개인 정보 수집에 동의하고 '상담 신청하기' 버튼을 누른다.
2. 상담 내용을 입력한다. 비어 있으면 같은 단계에서 안내를 받는다.
3. 상담 시간을 선택하고 필요하면 질의 응답을 포함한다.
4. 제목, 시간, 질의응답 설정을 확인하고 수정하거나 완료한다.
5. 설정 완료 안내를 확인하고, 필요하면 다시 설정한다.

### 인터렉션 시나리오

1. 시작과 녹음 활용 안내
- 행동, 이벤트: 기존 동의 체크박스를 선택하고 '상담 시작하기'를 클릭한다.
- 조건: 개인정보 수집 동의가 선택되었는가?
- 반응, 다음 상태: 동의 전에는 버튼을 누를 수 없다. 동의 후 클릭하면 상담 신청을 시작하는 안내 팝업이 열린다.
  - 팝업에서 '돌아가기'를 누르거나 Esc를 누르면 동의를 해제하고 시작 화면에 남는다.
  - '동의하고 신청하기'를 누르면 제목 입력 화면으로 전환된다.

2. 제목 입력
- 행동, 이벤트: 제목을 적고 '다음'을 클릭한다.
- 조건: 앞뒤 공백을 지운 제목이 비어 있는가?
- 반응, 다음 상태: 비어있으면 같은 화면에 오류를 표시하고 입력창에 초점을 둔다.
  - 값이 있으면 저장하고 조건 선택으로 이동한다.

3. 조건 선택
- 행동, 이벤트: 발표 시간을 바꾸거나 질의응답을 선택하고 '내용 확인하기'를 클릭한다.
- 조건: 질의응답을 선택했는가?
- 반응, 다음 상태: 선택했을 때만 질문 수를 보여준다.

4. 내용 확인
- 행동, 이벤트: 제목, 시간, 질의응답 내용을 읽고 '수정하기' 또는 '신청완료'를 클릭한다
- 조건:수정인가, 완료인가?
-반응, 다음상태: 수정하면 기본 값을 유지하고 조건 선택으로 돌아간다.
                완료하면 완료 안내로 이동한다.
5. 완료와 다시 설정
-행동, 이벤트: 완료 안내를 열고 필요하면 '수정하기'를 클릭한다.
-반응, 다음 상태: 새 설정의 제목 시간, 질의응답, 진행상태를 초기화하고 제목 입력부터 다시 시작한다. 이미 확인한 녹응 활용 동의와 다른 기능을 유지한다.
